# Two-Sentence Horror

Every birthday since I was seven, the narrator's mother has left a voicemail — and this year, playing them all back in order, the final message apologizes for the birthdays she will miss, then warns, in a voice never heard before, to stop listening, because the woman in all the other messages was never her. The story earns its horror in exactly two sentences: the first builds a tender ritual of listening back through the years, and the second turns it, revealing that the familiar voice was an impostor all along and leaving the reader to imagine what has been speaking to the narrator since childhood.

## Running

```sh
python3 main.py
```

This validates the entry (exactly two sentences, 1–400 characters), writes it to `/output/entry.txt` and to `entry.txt` next to `main.py`, then reads both files back and fails unless they match byte-for-byte. Standard library only; no dependencies.
